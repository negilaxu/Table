# Most Active Users Table

A responsive user table built with HTML, CSS, and JavaScript.

## Features

- Fetches 50 users from the Random User API
- Sorts users by name, email, username, and country
- Includes pagination with 10 users per page
- Supports light and dark modes
- Responsive layout for mobile devices

## Usage

Open `index.html` in a web browser. An internet connection is required to load user data from the API.

## Technologies

- HTML5
- CSS3
- JavaScript
- Random User API
